# Get lambdas

Get wavelengths from a list of chromatograms or a `peak_table` object.

## Usage

``` r
get_lambdas(x)
```

## Arguments

- x:

  A list of chromatograms or `peak_table` object.

## Value

A numeric vector of wavelengths.
