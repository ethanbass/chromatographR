# Summarize peak table

Computes basic statistics about a `peak_table` (e.g., the number of
peaks, wavelengths, range of intensities), which print as a formatted
summary.

## Usage

``` r
# S3 method for class 'peak_table'
summary(object, ...)
```

## Arguments

- object:

  A
  [`peak_table`](https://ethanbass.github.io/chromatographR/reference/peak_table-class.md)
  object.

- ...:

  Additional arguments (currently unused).

## Value

A list containing basic information about the supplied `peak_table`.
