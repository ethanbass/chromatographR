# Preprocessed goldenrod root chromatograms

A list of four pre-processed HPLC-DAD chromatograms derived from the raw
data stored in
[`Sa`](https://ethanbass.github.io/chromatographR/reference/Sa.md).
Retention times are stored in rows and wavelengths are stored in
columns. The time axis is interpolated from the 0.0067-minute interval
of [`Sa`](https://ethanbass.github.io/chromatographR/reference/Sa.md) to
0.02 minutes, to save space and processing time.

## Usage

``` r
data(Sa_pr)
```

## Format

A list of four pre-processed matrices (434 timepoints × 60 wavelengths).
