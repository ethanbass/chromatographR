# Peak Table Object

S3 objects of class `peak_table` store chromatographic peak data along
with associated metadata and reference spectra.

## Components

A `peak_table` object contains the following elements:

- `tab`: The peak table itself — a `data.frame` of intensities in a
  sample × peak configuration.

- `pk_meta`: A `data.frame` containing peak metadata (e.g., the spectral
  component, peak number, and summarized retention time). See
  [`get_peaktable`](https://ethanbass.github.io/chromatographR/reference/get_peaktable.md)
  for its rows.

- `sample_meta`: A `data.frame` of sample metadata: the fields added to
  the chromatograms with
  [`chromConverter::add_metadata()`](https://ethanbass.github.io/chromConverter/reference/add_metadata.html)
  (chromConverter 0.11.0 or later), and any attached with
  [`attach_metadata`](https://ethanbass.github.io/chromatographR/reference/attach_metadata.md).
  `NA` if there are none.

- `instrument_meta`: A `data.frame` of instrumental metadata transferred
  automatically from the chromatograms.

- `ref_spectra`: A matrix of reference spectra (in a wavelength × peak
  configuration). `NA` until added with
  [`attach_ref_spectra`](https://ethanbass.github.io/chromatographR/reference/attach_ref_spectra.md).

- `args`: A list of the arguments given to
  [`get_peaktable`](https://ethanbass.github.io/chromatographR/reference/get_peaktable.md)
  to generate the peak table, with the peak list's fitting settings. See
  [`get_peaktable`](https://ethanbass.github.io/chromatographR/reference/get_peaktable.md).

## Methods

The following methods are available:

- [`print.peak_table()`](https://ethanbass.github.io/chromatographR/reference/print.peak_table.md)

- [`dim.peak_table()`](https://ethanbass.github.io/chromatographR/reference/dim.peak_table.md)

- [`head.peak_table()`](https://ethanbass.github.io/chromatographR/reference/head.peak_table.md)

- [`tail.peak_table()`](https://ethanbass.github.io/chromatographR/reference/head.peak_table.md)

- [`row.names.peak_table()`](https://ethanbass.github.io/chromatographR/reference/row.names.peak_table.md)

- [`subset.peak_table()`](https://ethanbass.github.io/chromatographR/reference/subset.peak_table.md)

- [`summary.peak_table()`](https://ethanbass.github.io/chromatographR/reference/summary.peak_table.md)

- [`[.peak_table`](https://ethanbass.github.io/chromatographR/reference/sub-.peak_table.md)

## See also

[`get_peaktable()`](https://ethanbass.github.io/chromatographR/reference/get_peaktable.md)
for creating `peak_table` objects
