# Print peak table

Print peak table

## Usage

``` r
# S3 method for class 'peak_table'
print(x, ...)
```

## Arguments

- x:

  A
  [`peak_table`](https://ethanbass.github.io/chromatographR/reference/peak_table-class.md)
  object.

- ...:

  Additional arguments to [`print`](https://rdrr.io/r/base/print.html).

## Value

Prints and invisible returns the `tab` element from the supplied
`peak_table`.
