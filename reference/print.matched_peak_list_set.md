# Print a set of matched peak lists

Prints a summary of a `matched_peak_list_set`: its wavelengths, the
reference sample, and the reference peaks and targets at each
wavelength.

## Usage

``` r
# S3 method for class 'matched_peak_list_set'
print(x, ...)
```

## Arguments

- x:

  A `matched_peak_list_set` object.

- ...:

  Additional arguments (ignored).

## Value

Invisibly returns `x`.
