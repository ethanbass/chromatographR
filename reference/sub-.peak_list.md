# Subset peak list

Subsets a `peak_list` while preserving metadata attributes.

## Usage

``` r
# S3 method for class 'peak_list'
x[i, j, ..., drop = FALSE]
```

## Arguments

- x:

  A `peak_list` object.

- i:

  Indices specifying elements to extract.

- j:

  Not used.

- ...:

  Additional arguments (ignored).

- drop:

  Not used.

## Value

A `peak_list` object.
