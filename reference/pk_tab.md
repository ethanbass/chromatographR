# Goldenrod peak table

A peak table generated from the exemplary goldenrod root extracts stored
in [`Sa`](https://ethanbass.github.io/chromatographR/reference/Sa.md).

## Usage

``` r
data(pk_tab)
```

## Format

A `peak_table` object.
